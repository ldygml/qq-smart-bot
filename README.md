# 给她爱：QQ 智能聊天机器人

“给她爱”是一个运行在 Windows 本机的 QQ AI 机器人。它通过 NapCat 接入 QQ 个人号，
使用阿里云百炼千问完成聊天、联网搜索、图片理解、文件总结和语音识别。

项目不只是“自动回复”：它维护短期聊天上下文、跨联系人的长期记忆、关系反思和成长
笔记，并配有开机手动启动、关闭、群聊免 @、群聊必须 @ 等一键脚本。

> **风险提示**
>
> 个人 QQ 号自动收发消息不属于 QQ 官方机器人接入方式，可能触发平台风控。建议只在
> 备用小号上运行，不要批量加人、营销或高频群发。需要长期稳定运营时，应使用
> [QQ 开放平台](https://q.qq.com/) 的官方机器人。

## 已实现功能

### 1. 真人化聊天人格

- 机器人人格名为“给她爱”，是一个有足球偏好、有脾气和判断的普通聊天对象。
- 普通闲聊短句、口语化，不默认写总结、列清单或输出客服模板。
- 会根据联系人、历史聊天和当前情绪调整语气。
- 可以冷嘲、拆台和直接指出问题，但不使用脏话、威胁、歧视或身份羞辱。
- 不主动声明“我是助手”；被直接询问时如实说明自己是 AI。
- 完整人格文件：[prompts/gexiai.md](prompts/gexiai.md)

### 2. 联网搜索和当前时间

- 每个请求都会带上当前日期和时间。
- 新闻、天气、比赛、比分、赛程、转会、伤病、政策、价格、热搜、“最新”“实时”等
  时效问题会自动启用千问联网搜索。
- 也可以显式搜索：

```text
/搜 今天有哪些重要足球新闻
/搜 杭州明天天气
```

- 要求模型优先使用带日期的可靠来源，不能把旧知识伪装成实时消息。

### 3. 多层记忆系统

机器人有三层记忆：

| 层级 | 内容 | 作用 |
|---|---|---|
| 短期上下文 | 每个会话最近 40 条消息 | 连续聊天 |
| 长期事实 | 从对话中提取的人物偏好、计划、关系等 | 跨联系人回忆 |
| 对话片段 | 用户原话和机器人当时回复 | 跨群聊回忆具体对话 |

此外还有后台反思层：

- 每 30 分钟检查一次新记忆。
- 至少积累 5 条新记忆后进行关联分析。
- 可以发现不同人物、地点、项目、兴趣之间的关联。
- 反思结果带置信度，并形成 `/成长` 可查看的成长笔记。
- 不保存或展示隐藏思维过程，不宣称机器人具有意识。

系统支持两种记忆策略：

```dotenv
# 默认保护：私密记忆只允许当事人使用
MEMORY_PRIVACY_PROTECTION=true

# 完整共享：不同联系人可以互相使用提取后的记忆
MEMORY_PRIVACY_PROTECTION=false
```

当前项目支持完整共享模式。关闭保护后，健康、财务、秘密等私密内容也可能影响其他
联系人的回答，只应部署在所有参与者都知情并同意的小圈子。

记忆管理命令：

```text
/记忆
/删记忆 编号
/忘记我
/成长
```

### 4. 图片与题目理解

- 普通截图自动切换到 `qwen3-vl-plus`。
- 可以读取题目、公式、图表、选项和图片中的文字。
- 可以附带要求，例如“只给答案”“给出详细步骤”。
- 单条消息默认最多处理 3 张图片，机器人侧不限制图片大小。
- QQ 商城表情、`mface` 和带 `emoji_id/key` 的表情包不会被误判成题目图片。

### 5. 文件解析与总结

支持：

- 文字型 PDF
- Word `.docx`
- PowerPoint `.pptx`
- Excel `.xlsx`
- CSV、TXT、Markdown
- 常见代码和配置文件

长文档会先分段提炼，再生成最终总结。可以要求提炼行动项、风险、会议纪要、汇报提纲
或表格分析。默认一次最多处理 3 个文件。

扫描版 PDF 没有可提取文字时，可以改发页面截图。旧格式 `.doc`、`.ppt`、`.xls`
需要先另存为新版格式。

### 6. 语音识别

- QQ 语音由 NapCat 转换为 WAV，再交给 `qwen3.8-omni-flash`。
- 默认返回语音转写。
- 可以要求总结、回答语音里的问题或提取待办。
- 支持 `/转写`、`/听写`、`/总结`、`/回答`。
- 目前只返回文字，不合成语音回复。

### 7. 学习与工作工具

| 功能 | 命令 |
|---|---|
| 保存笔记 | `/记 标题 \| 内容` |
| 查看笔记 | `/笔记` |
| 搜索笔记 | `/查 关键词` |
| 删除笔记 | `/删笔记 编号` |
| 添加待办 | `/待办 内容` |
| 查看待办 | `/待办` |
| 完成待办 | `/完成 编号` |
| 添加提醒 | `/提醒 2026-11-05 09:00 复习第三章` |
| 查看提醒 | `/提醒` |
| 取消提醒 | `/取消提醒 编号` |

提醒按 `Asia/Shanghai` 时区解析，机器人每 15 秒检查一次。离线期间到期的提醒会在
机器人重启后补发。

常用的 AI 任务入口：

```text
/计划 两周内复习完线性代数
/总结 [粘贴材料]
/出题 线性代数第三章，出 5 道题
/翻译 [需要翻译的内容]
/润色 [需要修改的文字]
/解释 特征值和特征向量
```

### 8. QQ 互动

- 群聊和私聊都支持戳一戳：

```text
/戳
```

- 私聊也可以直接发“戳一戳”或“戳我”。
- 群聊可配置为“必须 @”或“无需 @”。
- 回复默认不引用；用户主动引用、发送媒体时才会引用原消息。
- 在“必须 @”模式下，直接引用机器人的回复可以继续追问，不必再次 @。
- 机器人会过滤 Markdown 星号、标题、表格和 emoji，输出适合 QQ 的纯文本。
- 长回复不会主动截断，会按 QQ 传输需要拆成多段。

```text
QQ 小号
   │
   ▼
NapCat + QQNT
   │  OneBot v11 HTTP
   ├──────────────► http://127.0.0.1:8080/onebot
   ▲                         │
   │                         ▼
   └─────────────── Python Bot (FastAPI)
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
          SQLite        千问模型 API     本地文件解析
       聊天/记忆/任务    文本/视觉/语音      PDF/Office/音频
```

默认模型分工：

| 用途 | 模型 |
|---|---|
| 普通闲聊 | `qwen3.8-flash` |
| 推理、总结、计划和联网搜索 | `qwen-plus` |
| 图片和题目 | `qwen3-vl-plus` |
| 语音转写 | `qwen3.8-omni-flash` |
| 长期记忆提取 | `qwen3.8-flash` |
| 后台关联与反思 | `qwen-plus` |

## 一键启动和关闭

### 启动

每次打开电脑后，双击：

[启动机器人.cmd](启动机器人.cmd)

脚本会自动：

1. 启动项目内的便携 NapCat。
2. 尝试用小号快速登录。
3. 等待 OneBot `3000` 端口上线。
4. 启动 Python 机器人。
5. 等待 `8080` 健康接口通过。

如果 QQ 登录态失效，脚本会打开 NapCat WebUI，扫码后自动继续。

### 关闭

双击：

[停止机器人.cmd](停止机器人.cmd)

只会关闭项目启动的机器人和便携 NapCat，不会关闭主 QQ。

### 群聊 @ 模式切换

- [群聊免艾特.cmd](群聊免艾特.cmd)：所有群消息都会回复。
- [群聊必须艾特.cmd](群聊必须艾特.cmd)：只有 @ 机器人或引用机器人回复时才响应。

两个脚本都会直接修改 `.env` 并重启 Python 机器人，不会重启 NapCat。

## 安装

### 1. 安装依赖

```powershell
cd E:\Vibe\qq-smart-bot
uv sync --dev
```

### 2. 配置 NapCat

在 NapCat WebUI 中配置：

1. HTTP 服务端：`127.0.0.1:3000`
2. HTTP 客户端：`http://127.0.0.1:8080/onebot`
3. 两处消息格式都使用 `array`
4. 两处 Token 都与 `.env` 中的 `ONEBOT_TOKEN` 一致

可参考 [config/onebot11.example.json](config/onebot11.example.json)。

### 3. 配置千问 Key

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\set-qwen-key.ps1
```

脚本会隐藏输入，把 Key 写入本地 `.env`。`.env` 已被 Git 忽略，不会上传。

### 4. 启动

双击 [启动机器人.cmd](启动机器人.cmd)，或运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

## 主要配置

完整模板见 [.env.example](.env.example)。

| 配置 | 默认值 | 说明 |
|---|---|---|
| `BOT_NAME` | 给她爱 | 机器人身份名 |
| `PERSONA_PROMPT_PATH` | `prompts/gexiai.md` | 完整人格提示词 |
| `LLM_MODEL` | qwen-plus | 任务和联网搜索模型 |
| `CASUAL_MODEL` | qwen3.8-flash | 普通闲聊模型 |
| `WEB_SEARCH_ENABLED` | true | 启用联网搜索 |
| `VISION_MODEL` | qwen3-vl-plus | 图片理解模型 |
| `AUDIO_MODEL` | qwen3.8-omni-flash | 语音识别模型 |
| `HISTORY_MESSAGES` | 40 | 短期上下文消息数 |
| `SHARED_MEMORY_ENABLED` | true | 跨会话长期记忆 |
| `MEMORY_PRIVACY_PROTECTION` | 可配置 | 私密记忆是否跨联系人隔离 |
| `REFLECTION_ENABLED` | true | 后台关联和成长笔记 |
| `REFLECTION_INTERVAL_SECONDS` | 1800 | 反思间隔 |
| `ENABLE_GROUP` | false | 是否启用群聊 |
| `GROUP_REQUIRE_MENTION` | true | 群聊是否必须 @ |
| `GROUP_ALLOWLIST` | 空 | 允许响应的群号 |
| `PRIVATE_ALLOWLIST` | 空 | 允许私聊的 QQ 号 |
| `QUOTE_REPLIES` | true | 是否按需引用原消息 |
| `RATE_LIMIT_PER_MINUTE` | 8 | 每个用户的 AI 请求上限 |
| `TIMEZONE` | Asia/Shanghai | 提醒时区 |
| `DATABASE_PATH` | data/bot.db | SQLite 数据库路径 |

修改 `.env` 后需要重启机器人。

## 数据与安全

- `.env`、API Key、聊天数据库、NapCat 和虚拟环境都不会提交到 Git。
- 聊天和长期记忆保存在本机 SQLite。
- 模型会收到完成请求所需的文字、图片、文档内容或音频。
- 图片和文件默认不长期保存原文件。
- 完整共享模式可能把一个人的信息用于另一个人的回答，需确保参与者知情。
- 不使用真实 QQ 密码；登录由 NapCat 扫码完成。
- 不要把 `.env`、API Key 或 QQ 登录凭据发给其他人。

## 已知限制

- 个人 QQ 自动化存在风控风险。
- 扫描版 PDF 不能直接提取文字，需要发送页面截图。
- 超大图片、文件和音频仍受 QQ、阿里云接口和本机资源限制。
- 联网搜索依赖模型服务可用性和第三方来源质量。
- 长期记忆和反思是模拟连续人格，不代表真正意识。
- 不同联系人的语气会基于历史调整，但核心人格和真实性边界不会自动改变。
- “给她爱”不会主动声称真人；被直接询问时会说明自己是 AI。
